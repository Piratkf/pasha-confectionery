# Pasha Confectionery

Премиальная кондитерская. Статический сайт с роскошным дизайном, фильтром десертов, секциями с товарами, отзывами и кнопками заказа.

## Как запустить локально

Откройте файл `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```
